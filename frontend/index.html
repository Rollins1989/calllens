How scoring works

Every call is scored on three independent evaluation layers: deterministic checks (was a required step completed, did the tool call succeed), an LLM judge scoped to strictly semantic dimensions (relevance, clarity, empathy, instruction-following, naturalness), and reference-based checks against a knowledge base (hallucination detection) and a policy file (compliance). The weighted combination is configurable per bot type — see config.SCORING_WEIGHTS. Nothing here is a single unexplained number: open any call in the Calls tab to see the full point-by-point breakdown and the plain-English primary failure.
